# PDF RAG System with LangGraph & Pinecone

An end-to-end Retrieval-Augmented Generation (RAG) pipeline built with LangChain, LangGraph, Google Gemini, and Pinecone. The system loads a PDF user manual, chunks and embeds the document into a serverless vector index, and answers user queries via a graph-based execution workflow.

## Features

- **Document Processing**: Extracts text from local PDFs using `PyPDFLoader` and splits it into manageable chunks with `RecursiveCharacterTextSplitter`.
- **Vector Storage**: Uses Pinecone Serverless to host and index 768-dimensional document embeddings generated by Google Generative AI (`embedding-001`).
- **Graph Architecture**: Orchestrates state-driven retrieval and generation nodes using `LangGraph`.
- **LLM Integration**: Employs `gemini-2.0-flash` for factual generation based on retrieved context.

## Prerequisites

- Python 3.9+
- A Google Gemini API Key
- A Pinecone API Key
